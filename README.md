## ⚙️ Công nghệ & Package sử dụng

| Nhóm chức năng | Gói Flutter liên quan |

| Networking | `http`, `FutureBuilder`, `jsonDecode` |
| Local Storage | `Hive`, `sqflite` |

## 🧠 Kiến thức đạt được
Sau khi hoàn thành 10 dự án, sinh viên có thể:
- Thiết kế giao diện Flutter **đẹp và có tính phản hồi cao (responsive)**  
- Sử dụng các **cơ chế quản lý trạng thái** khác nhau  
- Kết nối và xử lý dữ liệu từ **API bên ngoài**  
- Lưu trữ dữ liệu bằng **Hive / SQLite / Firebase**  
- Triển khai tính năng **camera, thông báo, định vị, và xác thực người dùng**
